# Backlog

Features and improvements queued for implementation. Both AI agents and the user can add items.

## Format

- Each item should include a brief description
- Mark items as [ ] (pending) or [x] (completed)
- AI moves items here from wishlist when user approves

## Instructions for AI

- **Wishlist**: Freely add ideas when you spot opportunities (features not handled by aliases)
- **Backlog**: You may add items directly, but only if they are **truly worthy** — actionable, well-scoped, and clearly valuable. Do not add speculative or low-value items.
- **Quality gate**: Before adding to backlog, ask: "Would the user actually want this implemented?" If unsure, put it in wishlist instead.
- **Reporting**: Any backlog entry you add MUST be listed in your cron run report so the user can review.
